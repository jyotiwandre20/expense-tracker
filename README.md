# 💰 Expense Tracker

A simple and professional web application to track and manage daily expenses.

## 🚀 Live Demo

Coming soon...

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Bootstrap 5
- HTML
- Jinja2

## ✨ Features

- ➕ Add expenses
- 📋 View all expenses
- 🔍 Search expenses by title
- 🏷️ Filter expenses by category
- 💰 Calculate total expenses
- ✏️ Update expenses
- 🗑️ Delete expenses
- ✅ Form validation
- 🔔 Flash success/error messages
- 📱 Responsive Bootstrap UI
- 🗄️ Database storage
